# Rick and Morty Characters (Flutter App)

Мобильное приложение, отображающее персонажей из вселенной "Rick and Morty" с использованием GraphQL, Hive, Provider и поддержкой тёмной темы.

## 🧩 Функции

- Список персонажей с пагинацией
- Избранное с сортировкой
- Кеширование данных офлайн (Hive)
- Поддержка тёмной/светлой темы
- Анимации и красивый UI в стиле Material 3

## 🚀 Технологии

- Flutter 3+
- GraphQL (`graphql_flutter`)
- Provider
- Hive
- flutter_launcher_icons
